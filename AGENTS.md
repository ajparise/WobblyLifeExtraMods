# Project workflow

- After completing changes to this mod, create a descriptive Git commit and push it to the configured GitHub repository.
- Do not create, publish, edit, or replace a GitHub release unless the user explicitly asks for a release.
- Building and installing the mod locally does not imply permission to create a GitHub release.
- After building each mod update, also install the verified plugin DLL to the remote Wobbly Life installation at `Z:\BepInEx\plugins\WobblyLifeExtraMods\WobblyLifeExtraMods.dll`. Check availability and report if remote installation or compatibility verification fails; do not silently skip it. Keep existing remote data safe, and do not interrupt a running game.
